# Jämmer 0.5.1

En rättelse av något som 0.5.0 kunde göra. Kräver macOS 27 eller senare på Apple-kretsar.

## Rättat

- **Omnibaren kunde låta dig vänta.** När det du skriver i omnibaren (⌘K) kan vara antingen ett kommando eller en begäran, frågar Jämmer Apples modell på din Mac vilket det är, och väntar högst tre sekunder. I 0.5.0 höll inte den gränsen när modellen var sen med svaret: omnibaren väntade så länge det tog. Nu avgör den vid gränsen och skickar texten till assistenten.
