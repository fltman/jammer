# Command palette

Press **⌘K** (or choose **Edit › Command Palette…**) and type part of a command's name, for example `norm` or `fade`. The letters only need to appear in order.

- **↑ / ↓** move between matches; **Return** runs the highlighted command; **Esc** closes the palette. You can also click a command.
- The palette lists transport and view commands, export, loudness measurement, agent access, and every editing operation with its presets (fades, silence, crop, gain ±1 and ±6 dB, and the four normalize targets).

The palette, the menus and the agent API share one list of operations, so a command works the same way wherever you start it.
