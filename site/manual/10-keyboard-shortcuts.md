# Keyboard shortcuts

## File

| Shortcut | Command |
|---|---|
| ⌘N | New |
| ⌘O | Open… |
| ⌘W | Close |
| ⌘S | Save… (for a clip from Flimmer: Save Back to the clip) |
| ⇧⌘S | Duplicate (for a clip from Flimmer: Save a Jämmer Copy…) |
| ⇧⌘I | Import Tracks… |
| ⇧⌘E | Export Audio… |
| ⌥⌘B | Batch… |
| ⌘, | Settings… |
| ⌘Q | Quit Jämmer |

## Edit

| Shortcut | Command |
|---|---|
| ⌘Z / ⇧⌘Z | Undo / Redo |
| ⌘X / ⌘C / ⌘V | Cut / Copy / Paste |
| Delete | Delete the selection |
| ⌘A | Select All |
| Esc | Clear the selection (in the spectrogram: the drawn area first) |
| ⌘K | Command Palette |

## Audio

| Shortcut | Command |
|---|---|
| ⌥⌘I | Fade In |
| ⌥⌘O | Fade Out |
| ⇧⌘L | Silence |
| ⌘T | Crop to Selection |
| ⌘] / ⌘[ | Gain +1 dB / −1 dB |
| ⌥⌘L | Measure Loudness |
| ⌥⌘M | Add Marker |
| ⌥⇧⌘P | Plugins… |
| B / L / P | In the spectrogram: box, lasso, brush |

## Transport

| Shortcut | Command |
|---|---|
| Space or ⌥⌘P | Play / Stop |
| Return | Go to Start |
| ← / → | Back / forward one second |
| Home / End | Start / end |

## View

| Shortcut | Command |
|---|---|
| ⌘+ / ⌘− | Zoom In / Out |
| ⌘0 | Zoom to Fit |
| ⌘E | Zoom to Selection |
| ⌥⌘T | Show or Hide Transcript |
| ⌥⌘A | Assistant: show it and put the cursor in its field; from the field, hide it |
| ⌥⌘S | Spectrogram or Waveform |
| ⌥⌘Y | Show History |
| ⌃⌘F | Full Screen |
| ⌘M | Minimize |

## Mouse and trackpad

| Gesture | Action |
|---|---|
| Drag in a lane | Select (in the spectrogram: draw an area with the current tool) |
| Shift-click | Extend the selection |
| Double-click | Select a clip |
| Click in the ruler | Move the playhead |
| Scroll | Move along the timeline |
| ⌘/⌥ + scroll, pinch | Zoom |

## Splash

| Shortcut | Command |
|---|---|
| ⇧⌘C | Copy the line for your agent |
| Return | Close |
