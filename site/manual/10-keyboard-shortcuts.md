# Keyboard shortcuts

## File

| Shortcut | Command |
|---|---|
| ⌘N | New |
| ⌘O | Open… |
| ⌘W | Close |
| ⌘S | Save… (for a clip from Flimmer: Save Back to the clip) |
| ⇧⌘S | Save As… |
| ⌥⇧⌘S | Duplicate (for a clip from Flimmer: Save a Jämmer Copy…) |
| ⇧⌘I | Import Tracks… |
| ⇧⌘E | Export Audio… |
| ⌥⌘B | Batch… |
| ⌘, | Settings… |
| ⌘Q | Quit Jämmer |

## Edit

| Shortcut | Command |
|---|---|
| ⌘Z / ⇧⌘Z | Undo / Redo |
| ⌘X / ⌘C / ⌘V | Cut / Copy / Paste |
| Delete | Delete the selection |
| ⌘A / ⇧⌘A | Select All / Deselect All |
| ⌘B | Split at Playhead |
| ⌘F / ⌘G | Find in Transcript / Find Next |
| Esc | Cancel a drag (an automation point's too: everything goes back); otherwise clear the selection (in the spectrogram: the drawn area first). In a dialog that only says something, Esc closes it as Return does |
| ⌘K | Omnibar: the keyboard to the field at the bottom of the window |

## Track

| Shortcut | Command |
|---|---|
| ⌥⌘X | Mixer… |
| ⌥⇧⌘P | Plugins… |

## Audio

| Shortcut | Command |
|---|---|
| ⌥⌘I | Fade In |
| ⌥⌘O | Fade Out |
| ⇧⌘L | Silence |
| ⌘T | Crop to Selection |
| ⌘] / ⌘[ | Gain +1 dB / −1 dB |
| ⌥⌘L | Measure Loudness |

## Repair

| Shortcut | Command |
|---|---|
| B / L / P | The spectrogram tools: box, lasso, brush (also **View › Tool**) |

## Transport

| Shortcut | Command |
|---|---|
| Space or ⌥⌘P | Play / Stop |
| Return | Go to Start |
| ← / → | Back / forward one second |
| ⌥← / ⌥→ | Nudge the clips in the selection (or the one under the playhead) on the current track 10 ms; with ⇧, 100 ms. Holding the key is one step |
| Tab / ⇧Tab | Select the next / previous clip on the current track |
| Home / End | Start / end |
| ⇧⌘M | Add Marker |

## View

| Shortcut | Command |
|---|---|
| ⌘+ / ⌘− | Zoom In / Out |
| ⌘0 | Zoom to Fit |
| ⌥⌘E | Zoom to Selection |
| ⌥⌘T | Show or Hide Transcript |
| ⌥⌘A | Assistant: show it and put the cursor in its field; from the field, hide it |
| ⌥⌘S | Spectrogram or Waveform |
| ⌃⇧⌘F | Focus Mode: hide the side panels |
| ⌃⌘F | Full Screen |
| ⌥⌘Y | Show History |
| ⌃⌘F | Full Screen |
| ⌘M | Minimize |

The keys for drawing automation lanes (⌥-click, ⌥→, ⌥Return and the rest) are in chapter 24, Automation.

## Tools

While the timeline has the keys, a letter picks a tool (also **View › Tool** and the tool palette):

| Key | Tool |
|---|---|
| A | Selection |
| S | Split |
| T | Trim |
| F | Fade |
| G | Gain |
| B / L / P | Box / Lasso / Brush (the spectrogram) |
| Z | Zoom |
| H | Hand |

## Mouse and trackpad

| Gesture | Action |
|---|---|
| Drag in a lane | Select, or what the current tool does (in the spectrogram: draw an area) |
| Drag an edge, a fade square or a marker | Trim, fade or move it; ⌃ while dragging turns snapping off |
| Shift-click | Extend the selection |
| Double-click | Select a clip |
| Click in the ruler | Move the playhead |
| Scroll | Move along the timeline |
| ⌘/⌥ + scroll, pinch | Zoom |
