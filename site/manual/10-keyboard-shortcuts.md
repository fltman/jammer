# Keyboard shortcuts

## File

| Shortcut | Command |
|---|---|
| ⌘N | New |
| ⌘O | Open… |
| ⌘W | Close |
| ⌘S | Save… |
| ⇧⌘S | Duplicate |
| ⇧⌘E | Export Audio… |
| ⌘Q | Quit Jämmer |

## Edit

| Shortcut | Command |
|---|---|
| ⌘Z / ⇧⌘Z | Undo / Redo |
| ⌘X / ⌘C / ⌘V | Cut / Copy / Paste |
| Delete | Delete the selection |
| ⌘A | Select All |
| Esc | Clear the selection |
| ⌘K | Command Palette |

## Audio

| Shortcut | Command |
|---|---|
| ⌥⌘I | Fade In |
| ⌥⌘O | Fade Out |
| ⇧⌘L | Silence |
| ⌘T | Crop to Selection |
| ⌘] / ⌘[ | Gain +1 dB / −1 dB |
| ⌥⌘L | Measure Loudness |
| ⌥⌘M | Add Marker |

## Transport

| Shortcut | Command |
|---|---|
| Space or ⌥⌘P | Play / Stop |
| Return | Go to Start |
| ← / → | Back / forward one second |
| Home / End | Start / end |

## View

| Shortcut | Command |
|---|---|
| ⌘+ / ⌘− | Zoom In / Out |
| ⌘0 | Zoom to Fit |
| ⌘E | Zoom to Selection |
| ⌥⌘T | Show or Hide Transcript |
| ⌃⌘F | Full Screen |
| ⌘M | Minimize |

## Mouse and trackpad

| Gesture | Action |
|---|---|
| Drag in a lane | Select |
| Shift-click | Extend the selection |
| Double-click | Select a clip |
| Click in the ruler | Move the playhead |
| Scroll | Move along the timeline |
| ⌘/⌥ + scroll, pinch | Zoom |

## Splash

| Shortcut | Command |
|---|---|
| ⇧⌘C | Copy the line for your agent |
| Return | Close |
